Single GCP Compute Engine VM · Caddy (TLS + Basic-auth gate) · embedded Chroma on a persistent disk · Gemini generation
0 / 00%
Topology, on purpose: embedded ChromaDB is a single-writer local store and the image is a heavy warm container, so one vertically-scaled node beats a cold-starting fleet. Managed container services (Cloud Run / Fargate) are the wrong tool here — they give no real persistent local disk. The scale-out path (Chroma→client/server, rate-limit→Redis) is documented for when one node is genuinely outgrown.
