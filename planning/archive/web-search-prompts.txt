3. Ensure Formatting and Output are User Friendly
Prompt:
“Ensure that all web search results are formatted in a way that’s clear to the user:
	•	Each result should be a separate numbered bullet point.
	•	Display the title (bold), snippet (as a paragraph), and the clickable URL on a new line.
	•	Do not repeat the source as ‘DuckDuckGo’ or related boilerplate—just show real titles and URLs.
	•	Never show ad or sponsored content in any answer.”

Prompt:
“If the chosen search API returns no relevant results, provide a friendly fallback message:
‘Sorry, no relevant web results were found for your query. You may try rephrasing your question, or request a summary/explanation from the language model instead.’
